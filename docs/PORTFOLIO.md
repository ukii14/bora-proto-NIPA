## 개요
- 개인이 수집한 웹 링크와 PDF 자료를 키워드와 요약 정보로 정리해 다시 빠르게 찾아볼 수 있는 서비스
- 비슷한 주제의 글을 모아 중복을 줄이고 핵심 내용을 한눈에 보여줌
- 미리보기와 전용 뷰어, 원문 페이지 바로가기 제공

## 활용 데이터 — 2021 공모전 원본 모델 학습 시점 (AI-Hub, 음성/자연어)
- 문서요약 텍스트
- 도서자료 요약
- 논문자료 요약

> 위 데이터로 요약 모델을 학습한 부분은 협업 AI 모델 개발자가 담당함. 현재 코드에는 학습한 모델 파일이 포함되어 있지 않고, 요약은 공개된 한국어 모델(KoBART, `gogamza/kobart-summarization`)을 받아 추론만 수행하도록 구성됨.

## 시스템 구성
- `bora-web` — 사용자가 직접 쓰는 웹앱 (React + Node.js)
  - 회원, 게시글, 댓글, 태그, 좋아요, 검색 기능 담당
- `bora-crawler` — 웹페이지 수집과 요약을 처리하는 서버 (Flask + Selenium + KoBART)
  - 페이지 크롤링, 본문 추출, 한국어 요약 생성, 썸네일 캡처 담당
- 공유 저장소 — MongoDB Atlas (게시글·회원 정보를 같은 DB에서 사용)

## 기술 스택
- 프론트엔드 — React (CRA), Material-UI
- 웹앱 백엔드 — Node.js, Express, Mongoose
- 크롤러 백엔드 — Python, Flask, Gunicorn, PyMongo, Selenium, HuggingFace Transformers (KoBART)
- 인프라 — Docker Compose, Nginx 리버스 프록시
- DB — MongoDB Atlas

## 핵심 기능

### 화면 기능
- 웹페이지·PDF를 등록하면 요약·태그·썸네일이 자동으로 만들어짐
- 타일 / 리스트 두 가지 보기 + 다크 모드 전환
- 검색창 입력이 멈춘 뒤 약 0.35초 후 결과를 가져와 불필요한 호출 감소
- 목록 끝까지 스크롤하면 다음 글 묶음을 자동으로 이어서 불러옴 (마지막 글 ID 기준)
- 공개 / 비공개 글 분리 + 전체 글 / 내 글 보기 전환
- 상세 페이지에서 태그 추가·삭제, 댓글 작성·수정·삭제, 좋아요, 공유 링크 복사
- 본인이 쓴 글은 그 자리에서 바로 제목·원문 링크 수정
- 본인이 쓴 글은 메인 카드와 상세 페이지 어디서든 삭제

### 보안·인증
- 로그인 세션 14일 후 자동 만료
- 한 계정당 동시 로그인 5개 제한, 초과 시 가장 오래된 로그인 자동 정리
- 로그인·회원가입은 1분당 10회까지만 시도 가능 (무차별 시도 방지)
- 비밀번호는 단방향 해시로 저장 (bcrypt)
- 세션이 만료되면 화면 어디에 있든 자동 로그아웃 후 로그인 페이지로 이동
- 게시글·댓글·태그는 작성자 본인만 수정·삭제할 수 있도록 권한 확인

### 데이터 처리
- 페이지가 완전히 로드된 것을 확인한 뒤 화면을 캡처해 이미지 누락 방지
- 썸네일 파일명에 무작위 ID를 부여해, 같은 페이지를 다시 등록해도 이미지가 겹치지 않음
- 일반 브라우저로 보이도록 요청 헤더를 넣어 차단(403) 회피
- 한국어 요약은 공개 모델(KoBART)을 사용해 본문에서 핵심 문장을 생성. 모델 파일은 별도 저장 공간에 보관해 서버 재시작 시간을 줄임

## 설계에서 신경 쓴 부분 (SOLID 원칙)
- 기능 단위 책임 분리 — 라우터·상태 관리·커스텀 훅을 각자의 역할만 갖도록 나눔
- 에러 처리 한곳에서 관리 — 모든 API가 공통 미들웨어를 거치게 해, 새 기능을 추가할 때 같은 에러 처리 코드를 다시 쓰지 않음
- 통신 모듈 단일화 — 프론트의 모든 서버 호출이 한 모듈을 거치도록 해, 세션 ID 부착과 만료 시 처리를 한 곳에서 수행
- 응답 형식 표준화 — 모든 API가 같은 성공·실패 모양으로 응답해 프론트의 분기 처리 단순화

## 본인 기여
- 웹앱 전체(프론트엔드 + 백엔드) 단독 개발. 화면 기획과 UI 기획.
- 회원·게시글·댓글·태그·좋아요·검색 등 모든 기능의 API와 데이터 구조 설계
- 상태 관리 구조 정리 — 한 화면에서 바뀐 정보가 다른 화면에도 새로고침 없이 즉시 반영되도록 처리
- 보안 강화 — 세션 14일 만료, 동시 로그인 5개 제한, 로그인·회원가입 시도 횟수 제한, 세션 만료 시 자동 로그아웃 등을 새로 추가
- 사용 흐름 보강 — 무한 스크롤, 본인 글 즉시 수정·삭제, 다크 모드, 검색 입력 자동 지연 등 사용자 흐름 정비
- 검색 — 제목·태그·요약·본문 가중치를 둔 텍스트 검색 + 결과가 없을 때 보조 검색을 자동으로 수행하도록 구현
- (크롤러) 안정화·정합성 보강 — 페이지 로딩 완료 대기, 썸네일 파일명 무작위화, 웹앱과 크롤러의 작성자 정보 자동 보정, 요약 모듈을 쉽게 교체할 수 있도록 구조 분리. *AI 모델 개발과 크롤러 원구현은 협업 AI 모델 개발자가 담당함.*
